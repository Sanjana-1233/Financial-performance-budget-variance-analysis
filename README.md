# Financial Performance & Budget Variance Analysis

## Project Overview
This project analyzes financial performance by comparing budgeted amounts with actual amounts across departments, categories, regions, payment methods, and months.

## Tools Used
- Microsoft Excel
- Power BI

## Objectives
- Compare budget vs actual performance
- Calculate variance and variance percentage
- Identify areas with significant financial variances
- Analyze performance across departments, categories, regions, and months
- Build an interactive Power BI dashboard

## Data Analysis
The dataset contains 9,998 records and 13 columns.

Key analysis areas:
- Department
- Category
- Region
- Payment Method
- Monthly Performance
- Budget Amount
- Actual Amount
- Variance
- Variance %

## Key Findings
- Marketing had the highest departmental variance.
- Salaries had the highest category variance.
- The East region had the highest regional variance.
- UPI recorded the highest actual amount.
- Monthly analysis was used to identify changes in financial performance over time.

## Project Workflow
Raw Data → Data Cleaning → Excel Analysis → Variance Analysis → Power BI Dashboard → Business Insights

## Outcome
The project demonstrates practical skills in Excel-based financial analysis and Power BI dashboard development, with a focus on turning financial data into meaningful business insights.
